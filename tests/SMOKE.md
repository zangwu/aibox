# AI Box 全功能冒烟用例

> 对象：`release/win-unpacked` 打包版  
> 方式：Electron CDP（`--remote-debugging-port=9222`）  
> 脚本：`scripts/ui-smoke-full.py`

## 0. 前置

| ID | 步骤 | 期望 |
|----|------|------|
| P1 | 启动 `AI Box.exe` | 主窗口标题为 AI Box，左侧导航出现 |
| P2 | 带 CDP 参数启动 | `/json/list` 返回 page |

## 1. 导航

| ID | 步骤 | 期望 |
|----|------|------|
| N1 | 点「工具面板」 | 显示工具卡网格 |
| N2 | 点「预设市场」 | 显示预设列表 |
| N3 | 点「教程」 | 显示使用教程 |
| N4 | 点「设置」 | 显示版本/便携 Node/日志 |
| N5 | 侧栏标题区 | 含「AI Box」「本地 AI 工具盒子」 |

## 2. 工具面板

| ID | 步骤 | 期望 |
|----|------|------|
| T1 | 进入工具面板 | 有卡片，标题含「工具面板」 |
| T2 | 筛选「全部」 | 桌面版+CLI 都出现 |
| T3 | 筛选「桌面版」 | 仅桌面形态卡，标题含「桌面版」徽标 |
| T4 | 筛选「CLI」 | 仅 CLI 卡 |
| T5 | 筛选「★ 已收藏」 | 仅收藏卡（可为空） |
| T6 | 双卡片 | 同工具同时有「X 桌面版」与「X CLI」 |
| T7 | 热度 | 显示 `周xx`/`★xx` 原始量，无 `/100` |
| T8 | 点收藏心 | 单卡切换；桌面/CLI 互不影响 |
| T9 | 「重新检测」 | 短暂「检测中…」后恢复，卡片仍在 |
| T10 | 「刷新热度」 | 出现进度/结果文案 |
| T11 | 已装工具 | 状态为绿色版本/路径 |
| T12 | 未装桌面卡 | 有「商店/下载」 |
| T13 | 已装工具 | 有「卸载」；点开确认框含「确认卸载」 |
| T14 | 取消卸载 | 弹窗关闭，工具仍在 |
| T15 | 受管工具 | 有预设下拉框 |

## 3. 预设市场

| ID | 步骤 | 期望 |
|----|------|------|
| R1 | 进入预设市场 | 卡片列表 + 「共 N 个预设」 |
| R2 | 筛选「全部 / ★已收藏 / 已存 key / Codex…」 | 列表过滤正确 |
| R3 | 搜索框输入关键字 | 列表收窄 |
| R4 | 点预设爱心 | 收藏切换 |
| R5 | 本地备注输入 | 可编辑 |
| R6 | 星级 | 显示评分控件 |
| R7 | 「编辑」铅笔 | 打开编辑弹窗，ID 只读 |
| R8 | 「新建预设」 | 打开新建弹窗，可填字段 |
| R9 | 复制分享码 | 无崩溃 |
| R10 | 「前往」官网 | 用内置浏览器开 tab |
| R11 | 导入分享码入口 | 可打开导入框 |
| R12 | 订阅区 | 有 URL 输入与添加入口 |
| R13 | 内置预设 | 有「内置」徽标，删除按钮对内置不可用/不消失列表 |

## 8. 破坏性/重操作（已自动化 `scripts/ui-smoke-destructive.py`）

| ID | 步骤 | 期望 |
|----|------|------|
| D1 | UI 点卸载 Codex 并确认 | npm 包卸载，PATH 无 codex，UI 显示未安装 |
| D2 | UI 一键安装 Codex | PATH 恢复 codex，UI 检出已装 |
| D3 | `applyPreset` + 假 key 写入 | `~/.codex/config.toml` 生成且含 provider/wire_api |
| D4 | 设置页下载便携 Node | `getPortableNodeStatus().installed == true` |
